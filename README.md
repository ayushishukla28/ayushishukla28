# Ayushi Shukla — Portfolio

Personal portfolio site (HR & Data Analytics · MBA, NMIMS). Plain HTML/CSS — no build step.

## Publish on GitHub Pages (≈5 minutes)

1. Sign in to GitHub as **ayushishukla28**.
2. Create a **new public repository** named exactly:
   `ayushishukla28.github.io`
3. Click **"uploading an existing file"**, drag in `index.html`, `README.md` and the `assets` folder, then **Commit changes**.
4. Go to **Settings → Pages**. Under *Build and deployment*, choose **Deploy from a branch → `main` / `(root)`** → Save.
5. In 1–2 minutes the site is live at **https://ayushishukla28.github.io**

> Tip: add that link to your LinkedIn "Contact info" and "Featured" section.

## Editing

Everything is in `index.html`. Look for the `<!-- ... -->` comments:

- **Education** — add your undergraduate degree and any internships (copy the `<li>` block).
- **Projects** — the four cards are starter examples. Replace titles, descriptions and links with your real projects / repos.
- **Toolkit** — keep only skills you're comfortable discussing in an interview.
- **Resume** — add `resume.pdf` to the repo and uncomment the Resume button in the hero.
- **Photo** — replace `assets/ayushi.jpg` (portrait orientation works best).

Edits can be made directly on GitHub (click the file → pencil icon); the site updates automatically after each commit.
